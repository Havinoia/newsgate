# NewsGate Intelligence Dashboard

**NewsGate** is a professional-grade, high-fidelity intelligence command center and real-time news aggregator. Designed for analysts and traders, it provides a unified interface for global signal monitoring, risk assessment, and market alpha generation.

![NewsGate Preview](https://via.placeholder.com/1200x600/12131a/b4c5ff?text=NewsGate+Intelligence+Command+Center)

## 🚀 Key Features

- **Live Intelligence Stream**: Real-time synchronization with global news nodes, categorized by impact and sector (Crypto, Politics, Energy).
- **Deep Dive Analysis Panel**:
    - **SITREP (Situation Report)**: Comprehensive breakdown of current events with source verification.
    - **Risk Assessment**: Data-driven evaluation of volatility impact and geopolitical tension.
    - **Market Alpha**: Proprietary sentiment scoring and whale accumulation tracking.
- **Intelligence Map HUD**: A geographical visualization layer for tracking global events as they unfold.
- **Terminal Terminal**: Integrated technical analysis terminal featuring live market charts.
- **Intelligence Alerts**: Functional notification system for mission-critical market reminders and volatility spikes.
- **Rich Aesthetics**: Premium dark-mode interface utilizing glassmorphism, fluid animations (Framer Motion), and a custom design system.

## 🛠 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Infrastructure**: [Supabase](https://supabase.com/) (Database, Authentication, Realtime)
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: Google Material Symbols
- **Real-time Data**: Integrated background ingestion workers

## 📦 Getting Started

### Prerequisites

- Node.js 18+
- Supabase Project

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Havinoia/newsgate.git
   cd newsgate
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Create a `.env.local` file based on `.env.example`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) with your browser to see the command center.
